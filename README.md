This is the github hosuing the code and documentation for the DAW18 project by the build18 group Music Men. 

DAW18 is a software defined guitar pedal which can hold as many effects as you want at one time!

These effects are displayed on an LCD screen outside of the pedal so the guitarist can easily read what effect the pedal is on.

Furthermore, you can connect to this guitar pedal via ssh, allowing you to wirelessly upload effects.

This is all powered by the Teensy audio library, Liquid Crystal LCD library, and Raspberry Pi
